### 概要（4000文字以内）
```
油絵の具が乾くまでの目安を、5つの質問から見積もるアプリです。

■ 指触乾燥・重ね塗り・ワニス
下地・画用液・主な顔料・塗りの厚み・部屋の状態を選ぶと、指触乾燥の日数、重ね塗りができるころ、ワニスで保護できるころを出します。

■ ホルベイン公式カタログ全107色
色名・品番・顔料記号から色を選べます。選んだ色の公式の乾燥日数を基準に計算するので、白や黒のような遅乾の色も反映されます。

■ 予定に残す
指触乾燥の日を、iOSカレンダー・リマインダー・Googleカレンダーに登録できます。端末の通知で知らせることもできます。作品名を入れておけば、どの絵の予定かがタイトルで分かります。

■ メーカーで微調整
ホルベイン・クサカベ・マツダ・ウィンザー＆ニュートン・水可溶性など、絵の具の乾きやすさに合わせて係数を選べます。

■ 通信しません
アプリから外部へ送信することはありません。広告もありません。

※ 表示される日数は目安です。塗膜の厚み、湿度、換気で変わります。公式カタログの数値は 0.15mm 厚・25℃・湿度55% の室内で測ったものです。
※ iPhone（iOS 17.0 以上）・縦向き。
```
（510文字）

## 9. 未対応・提出前に判断がいること

1. **広告SDKもアプリ内課金も無い**ため、本番IDへの差し替えも商品登録も不要。広告を出さないぶん、「広告なし」を前面に出すかは概要の判断（いまは『広告もありません』と1行だけ書いている）。
2. **6本同時提出のスパム判定（ガイドライン4.3）**。同じ開発者から同じ分野のアプリをまとめて出すため、機能の違いが伝わるよう、概要とレビューメモで「何をするアプリか」を明確にしている。スクリーンショットもアプリごとに別の画面にすること。
3. **`PrivacyInfo.xcprivacy` が無い**。このアプリは UserDefaults も含め「必須理由API」を使っておらず、第三者SDKも入れていないため、Apple の必須要件には当たらないと判断している。ただし提出時に「プライバシーマニフェストが無い」と指摘される可能性はゼロではないので、空のマニフェスト（収集なし・追跡なし）を足すかは提出前に決める。このタスクでは Swift/リソースを変更していない。
4. 乾燥日数の計算式と係数は概要に書ききらず、サポートページで開示している（誤解を招く表現を避けるため「目安」と明記）。
